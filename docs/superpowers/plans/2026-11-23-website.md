# Myth Mayhem website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static Astro site with a landing page, a card gallery and the docs, fed from the game repo by `npm run sync`.

**Architecture:** `scripts/sync.mjs` reads `C:\Dev\Myth Mayhem` and writes committed output (Markdown docs, `src/data/cards.json`, AVIF/WebP in `public/media/`). Astro renders it statically: plain CSS with tokens from `DESIGN.md`, small vanilla `<script>`s for interaction, and `<ClientRouter />` for view transitions.

**Tech Stack:** Astro 5 (static), `sharp` (sync only), `node:test`, Playwright MCP for checks.

**Spec:** `docs/superpowers/specs/2026-11-23-website-design.md` (+ `BRIEF.md`)

## Global Constraints
- Never write to `C:\Dev\Myth Mayhem`. The sync is read-only on the game repo.
- All swap-points are in `src/config/site.ts` only: `version: "0.3.0"`, `downloads.windows.url = "https://github.com/Roj-xx/myth-mayhem-website/releases/latest/download/MythMayhem-Windows.zip"`, `downloads.android.url = "https://github.com/Roj-xx/myth-mayhem-website/releases/latest/download/MythMayhem-Android.apk"`, sizes `"TBC"` / `"312 MB"`, `trailer: "/media/trailer.mp4"`, `poster: "/media/hero-2560.webp"`.
- No protected-mystery resolution (relic, Awakening cause, why two Inheritors, original separation, faction motives).
- Filipino terms kept as-is. Cards are keyed by ID and shown by name.
- Every motion has a `prefers-reduced-motion: reduce` path. No horizontal scroll at 375 px. 16 px gutters on mobile.
- No UI framework, no animation library. Dependencies: `astro`, `sharp` only.
- No screenshots section.
- **No commits**: the user commits (BRIEF rule). The "Commit" steps below are replaced by "leave changes staged-ready".

## Review Focus
1. Cards.md cell with extra markup (`**Usog** *(Buyag / Balis)*`, `—`): the name must be "Usog", and `—` must become `null`, not the text "—". → Task 1 test `parses names and dashes`.
2. Card art file missing or named differently: the sync must not crash. It falls back to the card back and lists the card. → Task 1 test `missing art falls back`.
3. Autoplay blocked / reduced motion / Save-Data: the hero shows the poster and the buttons still sit above the fold at 375×667. → Task 4 Playwright check.
4. Gallery with JS disabled or zero search results: the full grid is shown without JS, and an "No cards match" message appears on zero results. → Task 5 check.
5. Duplicate headings in docs (GDD/Manual reuse titles): anchors must be unique and the TOC links must land. → Task 6 check.
